ORGANIC — THE LIVING LABORATORY

Unzip the folder, then double-click index.html to open the laboratory in your browser.
The main index.html contains its images, styles and animations and works offline.
External research links require an internet connection.

Use a landscape window for the full scene. Select organic compounds to update the
journal and illuminate the cell diagram. Click the journal to enlarge it.

The editable-source folder contains the separate HTML, CSS, JavaScript and images.
For editing, serve that folder with a local web server (for example, run
python3 -m http.server 8000 in editable-source, then open http://localhost:8000).
Edits there do not automatically update the standalone index.html.

Each compound appears only once per experiment. Reload the page to start again.
