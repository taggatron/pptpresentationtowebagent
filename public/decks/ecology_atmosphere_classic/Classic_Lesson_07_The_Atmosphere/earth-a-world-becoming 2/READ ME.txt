EARTH — A WORLD BECOMING

GET STARTED
1. Extract the ZIP folder.
2. Open index.html in your web browser.

The main index.html includes all artwork, animation code and sound generation.
No installation or internet connection is needed.

CONTROLS
Click a region to animate its chapter and display the explanation.
Keys 1–4 also select chapters. Escape closes the explanation.
Play the journey visits all four chapters automatically.
Use Replay, Pause, Sound and Full screen as needed.
Sound begins after you interact with the experience.

EDITING
The editable-source folder contains the separate HTML, CSS, JavaScript and
artwork files. Serve this folder through a local web server when editing;
browser security can restrict canvas image access when opening these separate
files directly. The main index.html avoids that restriction by embedding assets.

The green chapter begins with bare terrain and gradually grows into forest.
Plants stay within Earth's boundary. The sun includes animated solar storms.
