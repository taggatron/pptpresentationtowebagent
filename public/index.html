⏱

RAG Cognitive Processing Time Guide

Every slide is evaluated in real time using Rosenholtz Visual Clutter (2007) and Sweller Cognitive Load Theory (1988). The processing badge is color-coded to help teachers and students pace the lesson:

Low Processing ~5–19s · VCI < 4.5

Quick orientation, titles, key takeaway summaries, or single-concept slides requiring minimal working memory.

Medium Processing ~20–35s · VCI 4.5–6.9

Multi-zone conceptual layouts, technical vocabulary acquisition, and comparative dual callout diagrams.

High Processing ~36s+ · VCI ≥ 7.0

Dense scientific diagrams, multi-stage calculation formulas, active retrieval practice, or high-load synthesis.
